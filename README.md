# ⛳ ゴルフスコア管理（PWA）

楽天ゴルフスコアをイメージした、スマホで使うゴルフスコア管理アプリです。
ブラウザで動作し、ホーム画面に追加するとアプリのように使えます。データは端末内（IndexedDB）に保存されます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| ラウンド記録 | プレー日・スタート時間・ゴルフ場・コース（OUT→IN）・天気・同伴者 |
| スコア | 18ホールのパー・打数・パットを入力（ステッパー入力＋楽天風スコアカード表示） |
| 写真からスコア読取 | スコアカードを撮影 → Claude API がホール毎の打数・パットを読み取り（複数プレーヤーは選択） |
| 料金 | 費目別に記録。領収書を撮影 → Claude API が費目と金額を読み取り |
| 食事 | 5段階評価・メニュー・感想・写真 |
| ゴルフ場情報 | 楽天GORA API で検索し、住所・アクセス・評価・料金目安・コース情報・画像などを表示 |
| SNS投稿 | スコア画像（Instagram向け 4:5）を自動生成し、端末の共有メニューから X / Instagram 等に投稿 |
| 統計 | ベスト・平均スコア・平均パット・スコア推移グラフ・バーディ/ボギー率・累計料金 |
| バックアップ | 全データ（写真含む）を JSON で保存・復元 |

## 初期設定（アプリ内「設定」画面）

1. **Anthropic API キー**（写真読み取り用）
   [Claude Console](https://platform.claude.com/settings/keys) で発行します。従量課金です。
   キーは端末内にのみ保存され、読み取り時にブラウザから Anthropic API へ直接送信されます。
2. **楽天アプリID**（ゴルフ場検索用・無料）
   [楽天ウェブサービス](https://webservice.rakuten.co.jp/) でアプリを登録して取得します。
   アクセスキーが発行された場合はそれも入力してください。
   アプリ登録時の許可ドメインに、公開先のドメイン（例: `xxxx.github.io`）を登録してください。
3. **スコアカード上の自分の名前**（任意）— 写真読み取り時に自分の行を優先します。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 本番ビルド（dist/）
npm run lint
```

技術構成: Vite + React + TypeScript / Dexie（IndexedDB）/ vite-plugin-pwa / @anthropic-ai/sdk（`claude-opus-5-5`、構造化出力）/ 楽天GORA API

## 公開（GitHub Pages）

`main` ブランチへ push すると `.github/workflows/deploy.yml` で GitHub Pages に公開されます。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を「GitHub Actions」に設定してください。
スマホのカメラ・共有機能は HTTPS 上でのみ動作します。

## SNS投稿について

- 「X・Instagramに投稿」→「共有」で、OS の共有メニューから投稿先アプリを選びます（iPhone / Android の Safari・Chrome）。
- Instagram は投稿文が自動入力されないため、「投稿文をコピー」してから貼り付けてください。
- 共有メニュー非対応の環境（PC等）では「画像を保存」＋「X に文章だけ投稿」をご利用ください。

## 注意事項

- データはブラウザ内に保存されます。ブラウザのデータ削除や機種変更で消えるため、定期的にバックアップしてください。
- 写真の読み取り結果は必ず確認・修正してから保存してください。
